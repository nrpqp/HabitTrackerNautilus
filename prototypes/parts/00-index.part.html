Las maquetas son HTML autocontenido: se abren con file://, sin servidor ni build. Se regeneran con node prototypes/assemble.js a partir de prototypes/parts/. La geometría del anillo está calcada de src/utils/svg.js y src/constants.js, así que lo que ves aquí es trasladable tal cual.

Diferencia estructural con la app actual: aquí el SVG se construye una sola vez con la DOM API y después sólo se mutan atributos. La app hoy hace innerHTML completo en cada click, lo que mata cualquier animación en curso — es el techo real de todo lo demás.
